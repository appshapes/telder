**The version: `0.1.0`.** First release of a working feature set, so a minor, not `1.0.0`: Windows, the Desktop
app and the IDE extensions are unmeasured, and the layering of instructions is one day old. `0.0.0` is the
pre-release sentinel the release script refuses.

**What `[Unreleased]` should say: what it says now.** Two `### Added` entries, the TL;DR itself and the
adjustable instructions. They are written for the person, not the developer, and match what ships. The release
script renames the section; do not rename it by hand. The one wording fix needed ("a small model" while the
default is Opus) is in this commit.

**The release, in order:** `make release version=0.1.0 card=45` from a clean `master` with `gh` logged in. It
pulls, bumps the manifest, renames the changelog section, commits through `make push` (test and plugin-check run
again), tags `v0.1.0` and pushes the tag. Then `release.yml` runs for the first time ever: watch it
(`gh run list --workflow release.yml`). Its guard requires the manifest's version to equal the tag and the
changelog to have the section; then `gh release create v0.1.0 --latest` with the section as notes. If it fails
after the tag exists, fix the cause, delete the tag (`git tag -d v0.1.0 && git push --delete origin v0.1.0`) and
tag again by hand (`git tag -a v0.1.0 -m v0.1.0 && git push origin v0.1.0`); the script cannot be rerun on a tree
that is already pinned. A published tag is never moved.

**Open, and none of it blocks the release:**

- Unmeasured: Windows (the shebang, `python3` on `PATH`), the Desktop app and IDE extensions (how they render
  `displayContent`), a turn with several long text blocks (each gets a summary), a session with two or more
  plugins that also hook `MessageDisplay` (order of replacement unknown).
- Haiku 4.5 as `model` works but took 7 to 40 s when measured; the docs say so.
- Opus 5.5 took 26.8 s on the 352-word smoke fixture (`make hook-smoke`, 2026-09-30, one sample) against the
  four to five seconds measured on 200 words. Rjae raised the default `timeout` to 90 s for it (0.3.0); the
  hook's own timeout in `hooks.json` is 130 s, above the option's cap of 120.
- The `---` rule above the summary renders as a literal `---` line in the terminal; harmless.
- A `.telder.md` is repository text that can only reword a summary; documented, no switch to refuse it.
- No `evals/` suite; the agentic loop and the release-notes email are not ported (Rjae: wait).
- After the release, the two "Nothing to do" update paragraphs in the READMEs become true for the first time;
  `/plugin marketplace update telder` then `/plugin update tldr@telder` is the manual path.
