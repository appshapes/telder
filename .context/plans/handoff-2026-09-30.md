## What exists

  `MessageDisplay` command hook, the script `scripts/tldr-hook` (Python 3, stdlib), the `/tldr` skill
  (`instructions`, `off`, `on`, `status`). A summary was shown under a real reply in an interactive Claude
  Code 2.1.285 session with options passed through `--settings`, and headless in `-p` mode.
- **Adjustable instructions.** The `instructions`, `instructions_file` and `instructions_mode` options and a
  project `.telder.md`, layered before the fixed format rules; `/tldr instructions` shows the layers. A real run
  with "Write it in French." and a project file produced a French three-point list with the project's point first.
- **The repository.** `github.com/appshapes/telder`, public, `master`, private vulnerability reporting on. Two
  commits: `9ebb6d5 45: Create the tldr plugin`, `6f05619 45: Let the person adjust the instructions`. The
  marketplace is the repository itself: `/plugin marketplace add appshapes/telder`, `/plugin install tldr@telder`.
- **The gates**, all green locally: `make test` (39 tests, no login needed), `make lint`, `make plugin-check`,
  `make plugin-validate`. `make hook-smoke` makes one real summary. CI: `ci.yml` (`fast` on Ubuntu, `macos`);
  the first run failed on shellcheck 0.9.0's SC2015, the second commit fixed it, and its run (36756679977) was
  green on both jobs; the runner's version is printed by the inventory step and pinned in `CLAUDE.md`.
- **Ported from Brigade** and adapted: CLAUDE.md rules, `make push` chain, `plugin-check.sh`, `no-secrets.sh`,

  marketplace entry with auto-update, the environment strip by prefix.

## Not done, on purpose

- **No release yet.** The manifest says `0.0.0`. `make release version=0.1.0 card=45` cuts the first one; the
  changelog's `[Unreleased]` already describes it. Until then `/plugin install tldr@telder` installs from
  `master` at `0.0.0`.
- **The agentic loop and the release-notes email are not ported** (Rjae: "wait for now"). Both need secrets
  (`CLAUDE_CODE_OAUTH_TOKEN`, `GH_ACTIONS_TOKEN`, `RESEND_API_KEY`) and, in Brigade, Blacksmith runners; telder's
  workflows use plain `ubuntu-latest` and `macos-latest`.
- **No `evals/` suite** for `claude plugin eval`.
- **Not measured:** Windows (shebang, `python3`), the Desktop app and IDE extensions (their `MessageDisplay`
  rendering), several long text blocks in one turn (each would get a summary), a `.telder.md` that tries to
  subvert the summary (display-only, no tools: worst case a misleading list under one reply).
