# User

You use Claude Code, and you want the long replies summarized: Telder adds a short list under every reply that
runs past a few paragraphs, written by a model through your own `claude` login. Nothing to configure, no API
key.

## If you want to

| If you want to | Go to |
| --- | --- |
| install the plugin, move an install made under the old name, or remove it | [Install](install/README.md) |
| see what a TL;DR looks like, get one right now, pause them, or know why none appeared | [Use](use/README.md) |
| change what the summary focuses on, its language, how long a reply must be, which model | [Configure](configure/README.md) |
| update the plugin, or see what changed in a release | [Update](update/README.md) |
| know what leaves your machine and where it goes, or report a vulnerability | [Privacy](privacy/README.md) |

## Install

Two commands in Claude Code and a reload. [Install](install/README.md) also covers an install made under the old
name, and uninstalling.

## Use

A reply over about 300 words of prose ends with a rule, a heading with the time, and the points. [Use](use/README.md)
covers `/tldr`, pausing the summaries, and the cases where nothing is added.

## Configure

Eight options, all with working defaults, and instructions in layers: yours, a file of yours, the project's.
[Configure](configure/README.md) lists them and says how to set them.

## Update

Nothing to do, most of the time; `/telder:update` does it right now. [Update](update/README.md) says where each
release's changes are listed.

## Privacy

The reply goes to Anthropic through your own `claude`, and nowhere else. [Privacy](privacy/README.md) points at
the statement and says how to report a vulnerability.
