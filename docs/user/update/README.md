# Update

Claude Code updates the plugin for you; the only question is when. Each release says what it changed, and
nothing new leaves your machine without the privacy statement changing with it.

## If you want to

| If you want to | Go to |
| --- | --- |
| update the plugin right now | [Update right now](#update-right-now) |
| see what changed in a release | [Know what changed](#know-what-changed) |

## Update right now

1. Nothing to do, most of the time: Claude Code updates Telder in the background when it refreshes the
   marketplace, on its own schedule, and asks you to type `/reload-plugins`; do that.
2. To update right now: `/telder:update`, then `/reload-plugins`.

Details: [Update right now](update-now.md).

## Know what changed

1. `CHANGELOG.md` has a section per release, written for the person who uses the plugin: what you see, what to
   type, what leaves your machine.
2. The GitHub release of each tag carries the same section as its notes.

Details: [CHANGELOG.md](../../../CHANGELOG.md).
